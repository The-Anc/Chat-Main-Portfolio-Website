Connect your portfolio storage

The dashboard is included, but it needs your own free Supabase project to securely store uploads and admin access.

Follow the setup steps in README.md, then add your Supabase Project URL and anon/public key to supabase-config.js. Do not use a service-role key in website code.

Admin sign in

Sign in with the admin account you create in Supabase.

Connect Supabase to activate sign-in.

Publish new work

Add a video, reel or design to the matching portfolio section.

Images and MP4/WebM videos are supported. Large video files may need compression before upload.
